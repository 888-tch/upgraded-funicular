=================================================
📱 我的30天学习计划 - 手机安装与运行说明
=================================================

本压缩包内包含：
1. index.html       (优化后的主程序代码)
2. manifest.json    (应用配置文件)
3. sw.js            (Service Worker 离线缓存引擎)
4. icon-192.png     (192x192 应用图标)
5. icon-512.png     (512x512 高清应用图标)

-------------------------------------------------
方法一：直接在手机浏览器上“安装为原生桌面 App” (推荐, 最便捷)
-------------------------------------------------
PWA (渐进式 Web 应用) 是现代手机最推荐的轻量应用形式：
无广告、无需提交应用商店审查、离线可用、全屏无地址栏运行！

【步骤】：
1. 将解压后的文件夹上传至免费 Web 托管平台（如 GitHub Pages、Vercel、Netlify 或 Cloudflare Pages）。
2. 用手机浏览器打开网址：
   - iOS (Safari)：点击底部分享按钮 -> 选择“添加到主屏幕”。
   - Android (Chrome / Edge / 微信外部浏览器)：点击右上方菜单 -> 选择“安装应用”或“添加到主屏幕”。
3. 手机桌面即可生成专属图标，点击即可像普通 App 一样全屏离线使用！

-------------------------------------------------
方法二：将此项目打包生成 Android .apk 安装包 (1分钟完成)
-------------------------------------------------
如果你需要标准的 .apk 文件用于安卓直接安装：

1. 打开免费打包工具网站 PWABuilder (https://www.pwabuilder.com) 或 Web2App 转换器。
2. 输入你部署好的网址，点击 "Package for Android"。
3. PWABuilder 会自动检测项目中的 manifest.json 和 图标，并一键打包生成可供安卓安装的 .apk 安装包文件！

-------------------------------------------------
方法三：直接离线运行
-------------------------------------------------
如果你不想上传服务器，直接把 index.html 传到手机，用手机的浏览器（如 VIA、X 浏览器或 Chrome）直接打开 index.html 文件，也可完全正常使用所有打卡、提醒与保存功能！
